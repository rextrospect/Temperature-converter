# Temperature-converter
## ?
This is a CLI converter app, like you would see beginners make. That is the case here.

## why?
I'm learning rust and soon as project i will update this to feature every temperature unit found on __*https://en.wikipedia.org/wiki/Conversion_of_scales_of_temperature*__

## How to run?
Go to [[rust-lang.org]](https://rust-lang.org/), follow installation steps.
Download the release **source code**, extract the folders inside.
Go to **.../Temperature-converter/src** and cargo build / cargo run / cargo build --release.
This will make an executable file, run it.
